# واجهة React وTypeScript

## نفس المشروع ونفس المستودع

FastAPI في `app/` والبوت في `bot/`؛ الواجهة الجديدة في `frontend/`.
المستودع يستخدم pnpm workspace لإدارة حزم الواجهة دون تغيير Python أو قاعدة البيانات.
الواجهة القديمة محفوظة في `static/` ومتاحة من `/legacy` و`/Shakwa.html`.
لا تحذفها حتى تنتهي مراجعة انتقال جميع السيناريوهات.

## أول تشغيل محلي بعد pull أو clone

تحتاج Python 3.12 وNode.js 22.12+ أو 24 الموصى به وpnpm 10.26.1.
لا تنسخ node_modules أو .pythonlibs من Replit إلى جهازك.
احتفظ بملف `.env` المحلي؛ لا ترفعه إلى GitHub.

```bash
python -m pip install -r requirements.txt
pnpm install --frozen-lockfile
pnpm build
python -m dotenv -f .env run -- python run.py
```

إذا لم يكن pnpm مثبتاً، ثبّت إصدار pnpm المذكور باستخدام مدير الحزم الموثوق
على جهازك أو Corepack المتاح مع توزيعة Node لديك. لا تفترض أن كل نسخ Node تضم Corepack.

افتح `http://127.0.0.1:5000`.
FastAPI يقدم ناتج React من `frontend/dist/`، مع نفس API والجلسات والكوكيز.
إعادة تحميل رابط داخلي مثل `/employee/complaints` تعمل دون خادم React منفصل.
إذا لم تبنِ الواجهة بعد، الصفحة الرئيسية تستمر بعرض القديمة للتوافق؛
المسارات الجديدة لا تدّعي العمل وتطلب بناء React.

## التطوير مع تحديث فوري

شغّل الخادم والبوت في طرفية:

```bash
python -m dotenv -f .env run -- python run.py
```

وفي طرفية أخرى:

```bash
pnpm dev
```

افتح واجهة التطوير على `http://127.0.0.1:5173`.
Vite يمرر `/api` إلى FastAPI على 5000 ويحافظ على نفس الأصل من منظور المتصفح.
لا تعدّل عناوين API داخل المكوّنات، ولا تضف توكن بوت إلى متغير VITE_*؛
كل VITE_* قابل للظهور للمتصفح.

التشغيل الموحّد على 5000 يستخدم آخر build، وليس ملفات TypeScript مباشرة.
بعد تعديل الواجهة وتشغيل نسخة موحّدة، نفّذ `pnpm build` ثم حدّث المتصفح.

## تنظيم الملفات

- `frontend/src/app/`: تجميع التطبيق والمسارات.
- `frontend/src/features/`: ميزات مستقلة مثل الشكاوى والأدلة وإدارة الأدوار.
- `frontend/src/layouts/`: تخطيطات المواطن والموظف حسب التنفيذ.
- `frontend/src/shared/api/`: عميل API والأنواع والـhooks المشتركة.
- `frontend/src/shared/ui/`: مكوّنات مشتركة.
- `frontend/src/shared/i18n/`: نصوص الواجهة واختيار اللغة.
- `frontend/src/shared/styles/`: هوية الألوان والخطوط والحالات المتجاوبة.

لا تضع منطق الصلاحيات أو الوصول لقاعدة البيانات داخل React. إخفاء الأزرار
بحسب صلاحيات الجلسة لتحسين الاستخدام فقط؛ الخادم يبقى مصدر القرار.
الأنواع التي لا ينتجها OpenAPI الحالي، خصوصاً الردود الإدارية المركبة، موثقة
في عميل الواجهة؛ عند تغيير API عدّل الأنواع واختبارات العقود معها.

## اللغات والبيانات الحساسة

نصوص واجهة عربية وإنجليزية، مع RTL/LTR. ترجمات أسماء المديريات والأدوار
والصلاحيات تأتي من API وجدول اللغات، وليست أعمدة خاصة لكل لغة في React.
إضافة لغة بيانات لا تولد ترجمة لأزرار التطبيق آلياً؛ ملفات ترجمة الواجهة
تحتاج ترجمتها أيضاً.

الجلسات cookies فقط. لا تحفظ كلمة مرور أو رمز متابعة أو مفتاح استعادة
أو بيانات هوية في localStorage أو sessionStorage أو عنوان رابط عام.
مفتاح الاستعادة يصدر بطلب صريح، ويظهر مرة واحدة مع خيار حفظه؛ لا يصدر
تلقائياً لمجرد دخول صفحة أو تقديم شكوى.

## التحقق

```bash
pnpm typecheck
pnpm build
python -m dotenv -f .env run -- python -m pytest tests/ -q
```

اختبارات الواجهة القديمة تُشغَّل صراحة بوضع legacy لمنع ضياع التغطية
أثناء الانتقال. اختبارات React والمتصفح تستخدم قواعد اصطناعية منفصلة،
لا بيانات المواطنين أو جلسات العمل الحقيقية. لا يعتبر اختبار API
المحاكى إثباتاً لوصول رسالة حقيقية على تيليغرام.
