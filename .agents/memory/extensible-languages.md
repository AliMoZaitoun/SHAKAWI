---
name: Extensible languages
description: User requirement for extensible multilingual domain data.
---

دعم اللغات في المشروع يجب أن يسمح بإضافة أي لغة لاحقاً عبر جدول لغات مثل ar وen وfr، مع بقاء اسم الحقل name بدلاً من أعمدة منفصلة لكل لغة، وإرجاع المحتوى بحسب لغة المستخدم.

**Why:** المستخدم رفض صراحة اقتراح name_ar/name_en لأنه يريد لغات قابلة للإضافة مستقبلاً.

**How to apply:** احترم هذا الشرط عند تطوير ترجمة بيانات الأدوار والصلاحيات والمديريات. وافق المستخدم على تنفيذ التصميم العلائقي؛ لا ترجع إلى أعمدة ثابتة لكل لغة أو تنشئ أدواراً مختلفة لكل لغة.
