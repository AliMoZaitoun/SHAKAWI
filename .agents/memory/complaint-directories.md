# Hierarchical complaint routing

**Rule:** أثناء تقديم الشكوى، يبدأ المواطن من الجهة الأعلى ويستطيع تقديم الشكوى لهذه الجهة أو متابعة الاختيار إلى مديرية تابعة، بشكل متكرر حسب عمق الهرمية.

**Why:** المستخدم يريد أن تعكس خيارات البوت بنية المديريات الفعلية، وأن يحدد المواطن مستوى الجهة المقصودة بنفسه.

**How to apply:** حافظ على عرض الأبناء تحت الجهة المحددة مع خيار واضح لاختيار الجهة الحالية وخيار للرجوع، ولا تعرض جميع المديريات كقائمة مسطحة.
