المستخدم يريد واجهة React باستخدام TypeScript، داخل نفس المشروع ونفس المستودع حالياً؛ فصل المشاريع مؤجل للمستقبل.

يريد الستايل «عصري وقوي» والواجهات مريحة وقريبة من هوية المنصة الحالية، وتنظيم الملفات «نظيف وقابل للتوسع والصيانة بسهولة».

مع بقاء React هو الاتجاه الأساسي، طلب المستخدم أيضًا دعم إدارة هرمية المديريات في الواجهة القديمة الثابتة لتجنب تنزيل مكتبات React محليًا.

**Why:** المستخدم وافق صراحة على نهج إعادة بناء الواجهة فوق FastAPI القائم، وليس إعادة إنشاء النظام كله.

**Why:** المستخدم طلب دعم الواجهة الثابتة لهذا المسار تحديدًا لأن إعداد مكتبات React على جهازه يستغرق وقتًا.

**How to apply:** حافظ على هوية المنصة وواجهات الـAPI والجلسات، وافصل المكوّنات والميزات إلى ملفات مفهومة بدلاً من ملف واجهة ضخم. لا تحصر دعم هرمية المديريات في React وحده، ولا تعتبر ذلك إذنًا بتغيير الباك إند إلى JavaScript أو إنشاء مستودع جديد.
