name: Frontend direction

المستخدم يريد واجهة React باستخدام TypeScript، داخل نفس المشروع ونفس المستودع حالياً؛ فصل المشاريع مؤجل للمستقبل.

يريد الستايل «عصري وقوي» والواجهات مريحة وقريبة من هوية المنصة الحالية، وتنظيم الملفات «نظيف وقابل للتوسع والصيانة بسهولة».

أوضح المستخدم لاحقًا أن React هي واجهة الموظفين والمواطنين الأساسية، ولا يريد تكرار تطوير الواجهة القديمة؛ تبقى القديمة للتوافق فقط.

**Why:** المستخدم وافق صراحة على نهج إعادة بناء الواجهة فوق FastAPI القائم، وليس إعادة إنشاء النظام كله.

**Why:** المستخدم يريد فصل واجهة المواطن عن واجهة الموظف وتجنب صيانة الواجهتين معًا.

**How to apply:** نفّذ ميزات الواجهة الجديدة في React/TypeScript فقط، ولا تضف روابط دخول الموظفين إلى واجهة المواطن. لا تحذف الواجهة القديمة أو توسعها إلا بطلب صريح، وحافظ على FastAPI وواجهات الـAPI الحالية.
