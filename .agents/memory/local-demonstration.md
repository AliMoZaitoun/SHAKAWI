name: Local demonstration startup
description: User-confirmed local launch method after exporting source without runtime secrets.
---
أكد المستخدم نجاح تشغيل الموقع والبوت محليًا بأمر واحد يحمّل `.env` صراحة عبر `python -m dotenv` ثم يشغّل `run.py`، مع توجيه البوت إلى API المحلي على المنفذ 5000.

**Why:** التشغيل المنفصل سبّب التباسًا بين إعدادات البيئة ومشاكل الاتصال. بعد تجربة أمر التشغيل الموحد قال المستخدم «حلو اشتغل نظامي».

**How to apply:** حافظ على تعليمات عرض اللجنة بسيطة وبمدخل تشغيل واحد، ولا تفترض أن وجود `.env` وحده يعني تحميله. لا تطلب قيم الأسرار ولا تُعد تشخيص الاتصال من البداية بعد تأكيد نجاح التشغيل.
