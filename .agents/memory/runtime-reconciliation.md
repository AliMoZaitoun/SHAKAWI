---
name: Verify runtime after merges
description: Successful setup reconciliation may leave Python serving code loaded before a merge.
---
لا تعتبر نجاح تهيئة الدمج دليلًا كافيًا على أن عملية Python الجارية حمّلت المسارات الجديدة؛ الملفات الثابتة قد تتحدث بينما يبقى الخادم على نسخة مستوردة قديمة.

**Why:** بعد نجاح التهيئة والمصالحة ظهرت واجهة استعادة جديدة لكن مسارها الخلفي بقي غير موجود، وزال التعارض بعد إعادة تشغيل سير العمل المدار.

**How to apply:** افحص مسارًا جديدًا في الخادم الجاري بعد الدمج. إذا بقيت المسارات القديمة فأعد تشغيل سير العمل القائم بدل تشغيل خادم إضافي، ثم تحقق من السجلات والواجهة.
